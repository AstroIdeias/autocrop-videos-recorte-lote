# AutoCrop Vídeos — Recorte em Lote

Backup privado da versão `0.6.0-recorte-lote-20261108`.

## Download e instalação

Baixe o arquivo `AutoCropVideos_RecorteLote.zip` na página **Releases** deste repositório. Extraia tudo para uma única pasta e execute `AutoCropVideos.exe`.

## Melhorias incluídas

- Botão verde **✂ Recortar selecionados** acima da lista de vídeos.
- Processamento somente dos vídeos marcados, preservando o enquadramento individual.
- Status alterado para **Recorte pronto** após cada processamento.
- Barra individual em cada vídeo e barra geral abaixo da lista.
- Escolha da pasta de saída a cada exportação.

## Conteúdo deste repositório

- `AutoCropVideos_RecorteLote.zip` está disponível como arquivo da Release, pois o pacote é grande demais para o repositório comum.
- `manutencao-source.zip` contém os scripts e metadados usados para validar e reconstruir a versão.
- Os manifestos registram a versão e as verificações realizadas.

Este repositório é privado e serve como backup do projeto.
